Power Consumption Optimization of GPU Server With Offline Reinforcement Learning

IEEE Access · Volume 13 · 85826–85837 · 2025

Heechan Chung, Yeeun Lim, Jongchan Park, Taeho Lee, Tae-Young Kim, Hyungjun Kim, Donghwan Lee

KAIST · KT Research and Development Center

학술지 전체 본문 BibTeX

서버 로그에서 GPU 클록 제어를 학습하며 전력과 실행 시간을 함께 고려합니다.

주요 기여

합성 작업 부하

논문은 기준 방법 대비 전력 소비 3.62% 감소와 계산 시간 1.51% 단축을 보고합니다.

LLaMA-2 미세조정

보고된 전력 소비는 6.40% 감소하고 계산 시간은 1.27% 증가합니다.

작업 부하 의존성

실험은 팬 제어와 사전학습을 비교하며 개선 정도는 작업 부하 구조와 학습 데이터 분포에 따라 달라집니다.

논문 요약

이 페이지를 위해 작성한 논문 요약입니다.

다양한 작업 부하에서 서버 측정값을 수집하고 오프라인 강화학습 제어기를 학습합니다. 동적인 GPU 클록 제어에 구간별 팬 제어와 Q 네트워크 사전학습을 결합합니다. NVIDIA L40S 서버 실험에서 작업 부하에 따른 전력 절감과 실행 시간의 절충을 보고합니다.

문제 정의

연구 문제와 필요성

클록을 낮추면 전력은 줄지만 작업이 길어질 수 있고 냉각을 강화하는 데도 전력이 필요합니다. 서버 수준에서 이러한 결합 효과를 함께 고려해야 합니다.

문제에서 해법으로

방법의 작동 원리

대표성 있는 데이터 구성

합성 작업 부하로 온도, 사용률, 주파수, 전력 로그를 생성합니다. 배포 정책이 기록된 운영 조건에서 학습하므로 데이터의 범위가 중요합니다.

Sections III–IV, dataset construction

제어기 학습과 적용

제안된 TD3+BC 기반 방법은 Q 네트워크 사전학습과 구간별 팬 제어를 포함합니다. 보상은 전력 사용과 길어진 실행 시간을 함께 고려합니다.

Sections III–IV, reward and controller design

가정과 적용 범위
