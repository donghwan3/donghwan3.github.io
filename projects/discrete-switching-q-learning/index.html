Abstract

A summary of the paper, written for this page.

Asynchronous Q-learning is represented as an affine switching recursion with noise. A linear lower comparison system and a switching upper system enclose its trajectory. This construction yields finite-time error bounds for averaged estimates with a constant step size and clarifies the role of maximization bias.

The problem

Why this problem matters

The greedy policy changes with the estimate, so a fixed linear model cannot directly describe Q-learning. The switching representation keeps this dependence explicit.

From problem to solution

How the method works

Keep the affine and noise terms

The mode matrix is contractive in the sup norm, but the actual recursion also has an affine term and dependent noise. Stability of the mode matrices alone is not the full proof.

Section III-A, Proposition 1

Analyze comparison dynamics

Monotonicity gives pathwise lower and upper bounds. A Lyapunov estimate for the lower system and a bound on the comparison gap transfer to Q-learning.

Reading the guarantees

Assumptions and scope

Assumptions include independent state-action sampling with full coverage, discounted tabular values, bounded rewards and initialization, and a constant step size in (0,1). The main averaged-iterate guarantee should not be read as an exact final-iterate convergence theorem.
