Abstract

A summary of the paper, written for this page.

Agents seek the value of the average reward while observing only local rewards and communicating over random networks. The paper formulates off-policy linear evaluation and consensus together as a saddle problem. A projected stochastic primal-dual algorithm yields finite-time guarantees for averaged iterates.

The problem

Why this problem matters

No agent directly observes the global reward. Off-policy correction and agreement across agents must be incorporated into the same evaluation procedure.

From problem to solution

How the method works

Unify evaluation and consensus

The formulation includes the network constraint in the saddle function. Solution analysis identifies the desired common value parameter and bounds auxiliary solutions.

Sections IV–V, saddle-point formulation

Project stochastic updates

Importance ratios correct behavior-policy samples. Iterates are projected onto specified compact sets containing a solution, and the finite-time result uses averaged iterates with inverse-square-root step sizes.

Assumptions and scope

The analysis assumes the stated linear-feature, coverage, random-network and bounded-sampling conditions, plus suitable compact projection sets. The finite-time bounds concern averages and specific error measures, not every raw last-iterate parameter error.
