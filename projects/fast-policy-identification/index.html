Value iteration, policy identification, invariant sets, joint spectral radius

Beyond the Bellman Fixed Point: Geometry and Fast Policy Identification in Value Iteration

arXiv:2604.17457 · 2026

Donghwan Lee

Department of Electrical Engineering, Korea Advanced Institute of Science and Technology (KAIST), Daejeon, South Korea

Paper (PDF) arXiv Video BibTeX

A value function can identify optimal actions before its numerical values converge to the Bellman fixed point.

Key Contributions

A geometric target for policy identification

The practically optimal solution set contains Q-functions whose tie-broken greedy policies are optimal. An invariant tube around the constant-shift affine set supplies a tractable subset of this larger target.

An exact transverse error system

A stochastic-policy representation expresses the deterministic Bellman-max error exactly. Projection removes the uniform shift, allowing the remaining policy-relevant directions to be studied through a restricted joint spectral radius.

A conditional explanation of faster identification

The paper identifies mixing conditions under which the transverse rate is strictly smaller than the discount factor, and explains obstructions. It also distinguishes the dynamics before and after optimal policies become active.

Abstract

A summary of the paper, written for this page.

The usual contraction argument measures how Q-value iteration approaches one optimal value vector. This work instead studies when the greedy actions become optimal. Adding a constant to every optimal Q-value leaves those actions unchanged, producing an affine set of policy-equivalent values. A small invariant tube around that set guarantees optimal action selection. Projecting away the constant-shift direction reveals a restricted switching-system rate that can be faster than the usual discount-factor rate. The resulting theory separates finite policy identification from later numerical refinement of the values themselves.

The problem

When have the actions converged, even if the values have not?

Value iteration can keep changing all Q-values by nearly the same amount after their action rankings are already correct. A distance bound to the single optimal vector does not isolate this behavior. The problem is to certify permanent optimal action selection, quantify approach to a policy-equivalent set, and explain when that approach admits a faster rate than full value convergence.

From problem to solution

How the method works

Build an invariant policy-correct tube

Use the minimum gap between optimal and nonoptimal action classes. Any tube radius below half that gap guarantees optimal greedy choices; the Bellman operator maps the tube into a smaller tube. Ties among optimal actions remain allowed.

Section 5, Assumption 1 and Proposition 2, pp. 6-7

Project out the uniform-shift mode

Represent each error update with an auxiliary stochastic policy, then project orthogonally to the all-ones vector. Analyze products of the resulting restricted matrices with a common Lyapunov norm. This representation does not randomize value iteration.

Section 6, Lemmas 5-6 and Theorem 1, pp. 7-8

X1 = Q* + span(1)

Every point in this affine set adds the same constant to all optimal Q-values. Such a shift preserves action orderings and therefore preserves optimal greedy actions.

Main results

What the analysis establishes

Finite and persistent optimal action selection

The deterministic iterates enter a sufficiently small invariant tube in finite time. Every subsequent tie-broken greedy policy is optimal, even though the Q-vector need not yet equal the Bellman fixed point.

Proposition 2, Section 6 and Appendix D, Corollary 2

Faster transverse bounds when the spectral gap permits

Distance to the affine set decays at any admissible rate above the restricted joint spectral radius. A rate below the discount factor is available only when that radius is strictly smaller; prefactors still affect finite-time comparisons.

Theorem 1 and following discussion, p. 8

A second stage governed by optimal policies

After identification, only optimal-policy modes remain active. With a unique optimal policy, this becomes one linear system. The full value error may still retain a slower constant-shift component, even when transverse error decays faster.

Section 7 and Appendix D, Theorem 2 and Corollary 3

Reading the guarantees

Assumptions and scope

The proved identification results concern deterministic tabular discounted Q-value iteration. A Q-learning experiment illustrates related geometry but does not transfer the theorem to noisy updates. Strict transverse acceleration needs an additional switching-family condition; ergodicity of individual policy chains alone is insufficient. Constants and initial distance affect whether a finite-time bound improves. The displayed single Q-value-iteration trajectory already begins with an optimal greedy policy, so it illustrates tube entrance rather than first discovery of an optimal policy.

See the reviewed paper version for complete hypotheses, constants, and proofs.
