Abstract

A summary of the paper, written for this page.

Off-policy policy evaluation with linear features motivates stable gradient TD methods. This paper revisits GTD2 through primal-dual optimization and develops related variants. ODE stability and stochastic approximation connect their saddle points to almost-sure convergence, while numerical comparisons examine practical behavior.

The problem

Why this problem matters

Ordinary TD can diverge when off-policy sampling and linear approximation are combined. A common optimization description helps identify which changes preserve the desired solution.

From problem to solution

How the method works

Start from projected Bellman equations

A nonsingular projected Bellman matrix identifies a unique target parameter. Saddle formulations introduce auxiliary variables without requiring a model-based TD update.

Transfer ODE stability to stochastic learning

Primal-dual gradient dynamics provide the limiting ODEs. Diminishing step sizes and the stated noise conditions support stochastic convergence.
