Abstract

A summary of the paper, written for this page.

The main paper formulates LQR through trajectory-based primal variables and Q-function-based dual variables. Strong duality and saddle-point relations link the formulation to the Bellman equation. A model-free algorithm recovers controller updates from suitable state-input trajectories; the linked arXiv item provides additional applications as supplementary material.

The problem

Why this problem matters

Dynamic programming describes optimality, while optimization provides dual variables and constraints. A common formulation allows these viewpoints to inform Q-learning for linear systems.

From problem to solution

How the method works

Establish primal-dual equivalence

The optimization formulations include Q-function parameters. Strong duality and the KKT conditions connect their solutions to the optimal Riccati and Bellman solutions.

Reading the guarantees

Assumptions and scope

The main analysis assumes the stated LQR regularity conditions and a stabilizing initial policy. The model-free construction requires sufficiently informative trajectories and exact matrix relations; it is not a general finite-noisy-data guarantee. arXiv:1811.08475 is the supplement, not the main article.
