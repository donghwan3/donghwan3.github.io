Abstract

A summary of the paper, written for this page.

Target-based TD maintains separate online and target parameters for linear policy evaluation. Averaging, double and periodic variants update those parameters differently. The paper proves asymptotic convergence for the first two and develops a finite-sample analysis for periodic TD.

The problem

Why this problem matters

A target estimate changes the coupled learning dynamics. The question is when the online and target parameters still approach the projected Bellman solution.
